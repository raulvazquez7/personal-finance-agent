tally ai — slice 3 reference mockups

Approved with Raul on 2026-09-25 in the slice 3 brainstorm (spec: 2026-09-25-slice-3-design.md). Fake data. Layout, hierarchy, tokens and chart forms are the contract; pixel values are indicative. Build with shadcn/ui components and the chart library chosen in the spec.

Every click goes one level deeper; every level uses one template: header total + delta, a chart, the next level as chart + table, then the transactions (“See all” opens /transactions with the filters set).

3 · Group page (Shopping), “By category” switched on
